# Maryam's Lavender Portfolio

Build a polished, modern, fully responsive personal portfolio website for **Maryam Zulqarnain** using the attached resume as the **authoritative source of truth** for all personal, academic, professional, project, skills, award, certification, and contact information.

Do not invent information, add fake experience, change dates, or make unsupported claims. Use the resume content accurately, but improve the presentation and website copy so it feels polished and professional.

The website should position me as an **ambitious Business & Marketing student with interests in marketing, strategy, research, technology, and creative problem-solving.**

---

# 1. OVERALL DESIGN DIRECTION

Create a **premium, elegant lavender-themed personal portfolio**.

The aesthetic should be:

* Soft lavender
* Feminine but professional
* Minimal
* Sophisticated
* Modern
* Creative
* Clean
* Editorial / personal-brand inspired

Think **modern creative portfolio + professional business/marketing portfolio**, rather than a generic student website.

### Color palette

Use a refined lavender palette:

* Very light lavender/off-white for the main background
* Soft lavender for secondary backgrounds
* Medium muted purple for accents
* Deep plum/charcoal for primary text
* White for cards and contrast areas

Use subtle lavender gradients where appropriate.

Do NOT make it:

* Bright purple
* Excessively pink
* Childish
* Glittery
* Overly decorative
* Generic corporate blue
* A simple resume pasted onto a webpage

The design should feel like a **personal brand**.
